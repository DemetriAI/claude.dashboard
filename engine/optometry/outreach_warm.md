# Warm Outreach — optometry (Agent 6)

**Status for this run:** every target in `leads.csv` is **cold** (web-sourced, no prior relationship),
so there are no warm contacts to send *yet*. This file is the **ready system** — it activates the
moment you have a warm contact, plus a play to manufacture warmth (the fastest path to a fund of
referrals, which is where this becomes repeatable).

**Framework:** give-give-give-ask + **ACA** (Acknowledge, Compliment, Ask). Never hard-pitch.
**Rules:** 3 touches/contact · single CTA · **no pricing in T1** · <120 words/msg.

---

## Where warm contacts come from (work these first — highest conversion in the engine)
1. **Pilot clients → peer ODs.** After a good 7-day result, ask: *"Who's the one optometrist you'd
   actually grab a beer with?"* Optometry is a referral village.
2. **Your existing network.** Anyone who knows an independent OD — a single intro outranks 50 cold emails.
3. **Adjacent vendors.** Frame reps, lab/equipment reps, practice-management consultants — they know
   every owner in town and trade intros.
4. **Local optometric society / alumni.** One credible member vouching for you opens a dozen doors.

> Log each warm contact as a new row in `pipeline.csv` (stage `warm_contact`) so it doesn't get lost.

---

## The 3-touch warm sequence (fill and send)

**T1 — value first (ACA, no ask for the sale).** *Give.*
> Hey {{NAME}} — {{MUTUAL}} mentioned you run {{PRACTICE}} **[Acknowledge]**. I've been deep in how
> independent optometry practices stop losing after-hours calls, and what you've built is exactly the
> kind of indie that deserves to catch every one **[Compliment]**. I made you a 90-second teardown of
> where I think calls are leaking — want me to send it over? **[Ask: permission, not pitch]**

**T2 — short re-engage (2–3 days later).** *Give again.*
> Quick follow-up, {{NAME}} — here's that teardown: {{LOOM_LINK}}. One number jumped out: looks like
> ~{{PAIN_BAND}}/mo in missed-call bookings. No agenda — tell me if I'm off base.

**T3 — the ask (free pilot OR the intro, risk-reversed).** *Ask.*
> If it's useful, I'll build the fix for {{PRACTICE}} **free** and run it on your real phones for
> 7 days — you only continue if it catches calls. Worth 15 minutes? **And if it's not for you but you
> know an OD it *is* for — who comes to mind?** {{BOOKING_LINK}}

---
*VERIFY: 3 touches · single CTA each · no pricing in T1 · <120 words/msg. For a referral target, the
ask in T3 is the **introduction**, not the sale.*
